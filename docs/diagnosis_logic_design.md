## Q3. カテゴリ別深掘り質問

### A. ハリ・輪郭が選択された場合

**一般知識**: 肌のハリ・弾力は、真皮に存在するコラーゲンやエラスチンといった線維成分によって支えられています。加齢とともにこれらの線維成分は減少・変性し、あわせて表情筋や皮下脂肪の変化も加わることで、フェイスラインのゆるみやたるみとして現れると考えられています。

**Q3-A. どの部分が特に気になりますか?**
- フェイスライン全体のたるみ
- 首元・デコルテのゆるみ
- 目もと・口もとの表情ジワ

→ 該当製品: エッセンス プラス(カプセル美容液・輪郭サイエンス)、リッチ レイヤー クリーム(仕上げ)

### B. 乾燥による小ジワが選択された場合

**一般知識**: 肌表面の小ジワの多くは、角層のうるおい(水分)が不足し、肌のキメが乱れることで生じる「乾燥小ジワ」です。角層のバリア機能が低下すると水分が保持しにくくなり、うるおい不足がシワとして目立ちやすくなります。

**Q3-B. シワが気になる部分は?**
- 目もと(部分的な小ジワ)
- 顔全体(複数の年齢サイン)

→ 部分的 → ペプタイド ジェル(部分用美容液・抗シワ効能評価試験済み)
→ 顔全体 → フューチャー セラム(8つの年齢シグナルに対応・抗シワ効能評価試験済み)

### C. 毛穴・肌のざらつきが選択された場合

**一般知識**: 毛穴の目立ちやざらつきは、古い角質が肌表面に滞留し、ターンオーバー(肌の生まれ変わり)が乱れることで起こりやすくなります。皮脂分泌の変化や乾燥も、毛穴が目立つ一因とされています。

**Q3-C. 毛穴の悩みのタイプは?**
- ざらつき・角質のごわつき
- 毛穴の目立ち・キメの乱れ

→ リファイニング トーナー(角質ケア+うるおい)、ルミスパ iO(洗顔による毛穴ケア)

### D. くすみ・透明感が選択された場合

**一般知識**: 肌のくすみは、ターンオーバーの乱れによる古い角質の蓄積や、血行の滞り、乾燥による透明感の低下など、複数の要因が重なって生じるとされています。

→ レディアント デイ SPF22(輝き+UV) / フューチャー セラム(色調・透明感)

### E. 乾燥・うるおい不足が選択された場合

**一般知識**: 肌のうるおいは、角層内の天然保湿因子(NMF)や皮脂膜によって保たれています。加齢や外部環境(乾燥・紫外線)によってこれらが減少すると、水分保持力が低下し乾燥が進みやすくなります。

→ リッチ レイヤー クリーム(保湿仕上げ) / レディアント デイ SPF22(日中保湿)

### F. 紫外線・乾燥ダメージ対策が選択された場合

**一般知識**: 紫外線は肌の水分を奪うだけでなく、コラーゲン・エラスチンの分解を促す一因ともされ、日中の蓄積ダメージが将来的な肌老化サインにつながると考えられています。

→ レディアント デイ SPF22(SPF22・PA++)

### G. 洗顔・角質ケアを見直したい場合

**一般知識**: 洗顔は肌の土台を整える最初のステップです。過剰な洗浄や摩擦は必要な皮脂膜まで取り除いてしまう一方、洗浄不足は毛穴づまりや肌荒れの原因になるため、肌質に合った洗浄方法を選ぶことが重要とされています。

**Q3-G. 現在の肌質は?**
- ノーマル・混合肌 / 乾燥肌 / 脂性肌 / 敏感肌
→ ルミスパ iO + 該当肌質のトリートメント クレンザー(ノーマル/しっとり/さっぱり/デリケート)

### H. 頭皮・髪が選択された場合

**一般知識**: 髪のハリ・コシは頭皮の健康状態に左右されます。加齢や乾燥、血行不良などにより頭皮環境が乱れると、髪が細くなったり、ボリュームが出にくくなったりすると考えられています。

→ ニュートリオール スカルプ&ヘアー セラム(単体、またはガルバニック スパ併用でスペシャルケア)

## 補足: 表現面の注意点(後日調整予定と確認済みだが、設計時のメモとして記載)

- 「抗シワ効能評価試験済み」の表現が使えるのは、現時点でフューチャー セラムとペプタイド ジェルの2製品
- それ以外の製品については、「〜を目指す」「〜にアプローチ」等の穏当な表現に留める設計にしておくと、後日の薬機法調整が容易
- 各カテゴリの「一般知識」は皮膚科学の一般的な事実であり、特定製品の効能を保証するものではない。一般知識と製品紹介の間に「〜に着目したケアの一つとして」のようなクッション文言を挟み、断定的な因果関係の表現(例:「だからこの製品でエラスチンが増える」)を避ける設計にする
- **注意**: 現時点で「一般知識」セクションの内容には明確な出典(論文・教科書等)を付けていない。皮膚科学分野で広く知られている一般論として記載しているが、厳密な裏付けは未確認のため、公開前に出典確認または表現の見直しが必要
