# 実装指示書:ageLOC肌診断プラットフォーム

このドキュメントは、Claude Codeにそのまま渡して実装を依頼するための仕様書です。

---

## 1. プロジェクト概要

**目的**: ユーザーが肌・髪の悩みをサイト上で入力すると、科学的根拠(臨床データ)にもとづいた改善アプローチを提案し、Nu Skin ageLOC製品の案内、および運営者への個別相談(LINE誘導)につなげる診断型Webアプリケーション。

**利用者像**: 美容・健康に関心があり、スマートフォンから利用する個人。会員登録は不要(匿名利用)。

**ゴール指標**: 診断完了率、LINE相談ボタンのクリック率。

---

## 2. 技術スタック

- フレームワーク: Next.js(App Router推奨)
- データベース: 一般的なRDB(PostgreSQL等)。ORMはPrisma等、実装しやすいものを選定してよい
- 認証: 不要(匿名利用。将来的な会員登録は本フェーズでは実装しない)
- ホスティング: 未確定。ローカル/Vercel等、開発しやすい構成でまず動くものを優先
- 管理画面: 製品・臨床データ・質問項目を編集できる簡易管理画面(認証は簡易なものでよい。要件は本書セクション6参照)

## 3. データベース設計

以下のテーブルを実装する(詳細カラムは下記の通り)。

### 3.1 products(製品マスタ)
- product_id (PK, INT/自動採番)
- product_code (VARCHAR) — Nu Skin製品コード
- name_jp (VARCHAR) — 日本版製品名
- name_us_ref (VARCHAR) — 参照元US製品名(内部管理用、ユーザー非表示)
- category (VARCHAR) — 化粧水/美容液/クリーム/乳液/デバイス/付属品/ヘアケア
- price_jpy (INT)
- product_url (VARCHAR)
- is_active (BOOLEAN)
- created_at, updated_at (DATETIME)

### 3.2 product_clinical_data(臨床データ・成分要約)
- data_id (PK)
- product_id (FK → products)
- summary_text (TEXT) — 要約済み臨床データ・成分説明(オリジナル表現)
- has_anti_wrinkle_test (BOOLEAN) — 抗シワ効能評価試験済みフラグ
- source_url (VARCHAR)
- last_verified_at (DATE)

### 3.3 concern_categories(悩みカテゴリマスタ)
- category_id (PK, VARCHAR) — A〜H
- name (VARCHAR)
- description (TEXT)
- sort_order (INT)

### 3.4 concern_general_knowledge(カテゴリ別一般知識)
- knowledge_id (PK)
- category_id (FK → concern_categories)
- content_text (TEXT)
- is_source_verified (BOOLEAN) — **初期データはすべてFALSEで登録**(出典未確認のため)
- source_url (VARCHAR, nullable)

### 3.5 product_concern_map(製品×悩みカテゴリ紐付け)
- map_id (PK)
- product_id (FK → products)
- category_id (FK → concern_categories)
- priority (INT)

### 3.6 questions(質問マスタ)
- question_id (PK)
- step (INT)
- question_text (TEXT)
- question_type (ENUM: single_select, multi_select)
- parent_category_id (FK, nullable) — Q3深掘り質問の場合の親カテゴリ

### 3.7 question_options(質問の選択肢)
- option_id (PK)
- question_id (FK → questions)
- option_text (VARCHAR)
- sort_order (INT)

### 3.8 option_concern_map(選択肢→カテゴリ紐付け)
- map_id (PK)
- option_id (FK → question_options)
- category_id (FK → concern_categories)

### 3.9 diagnosis_sessions(診断セッション)
- session_id (PK, UUID)
- started_at (DATETIME)
- answers_json (JSON)
- line_redirect_clicked (BOOLEAN)

### 3.10 diagnosis_results(診断結果スナップショット)
- result_id (PK)
- session_id (FK → diagnosis_sessions)
- category_id (FK → concern_categories)
- recommended_product_ids (JSON)
- displayed_at (DATETIME)

## 4. 画面仕様

### 4.1 画面遷移
```
TOP画面 → Q1(基本属性) → Q2(気になる変化・複数選択) → Q3(カテゴリ別深掘り質問、選択数分繰り返し)
→ 診断結果画面 → LINE相談へのご案内(外部遷移)
```

### 4.2 TOP画面
- キャッチコピー、診断概要(3ステップ・所要時間目安)、「診断をはじめる」ボタン

### 4.3 Q1: 基本属性
- 年代(20代/30代/40代/50代以上・単一選択)
- 性別(女性/男性/回答しない・単一選択)
- プログレスバー表示(Step 1/3)

### 4.4 Q2: 気になる変化(複数選択)
- 選択肢A〜H(下記「5. 悩みカテゴリ一覧」参照)、カード形式・複数選択
- プログレスバー(Step 2/3)

### 4.5 Q3: カテゴリ別深掘り質問
- Q2で選択されたカテゴリの数だけ、該当する深掘り質問を1画面ずつ表示
- 各カテゴリの質問内容は「6. カテゴリ別質問・マッピング詳細」を参照
- プログレスバー(Step 3/3、内部進捗も表示)

### 4.6 診断結果画面(構成順)
1. 診断サマリー(選択された悩みカテゴリのタグ表示)
2. カテゴリごとの結果ブロック(繰り返し):
   - カテゴリ名の見出し
   - 一般知識の説明文(`concern_general_knowledge.content_text`)
   - クッション文言(例:「〜に着目したケアの一つとして」)
   - 該当製品カード(製品名・画像・価格・詳細リンク。`has_anti_wrinkle_test`がtrueの場合はバッジ表示)
3. おすすめのお手入れステップ(化粧水→部分用美容液→美容液→クリーム→(SPF乳液)の順で該当製品を並べる)
4. 個別相談CTA:「LINEで相談する」ボタン(LINE公式アカウントの友だち追加URLへ外部遷移。URLは運用者側で別途指定)

### 4.7 UI方針
- スマートフォン最優先のレスポンシブデザイン
- 選択式(タップ)を基本とし、テキスト入力は極力使わない
- 各画面の質問数を絞り、離脱を防ぐ

## 6. カテゴリ別質問・マッピング詳細

### A. ハリ・輪郭
- 一般知識: 肌のハリ・弾力は真皮のコラーゲン・エラスチンに支えられ、加齢とともに減少・変性し、表情筋や皮下脂肪の変化も加わってたるみとして現れると考えられている。
- 深掘り質問: 「どの部分が特に気になりますか?」→ フェイスライン全体のたるみ / 首元・デコルテのゆるみ / 目もと・口もとの表情ジワ
- 該当製品: エッセンス プラス、リッチ レイヤー クリーム

### B. 乾燥による小ジワ
- 一般知識: 角層のうるおい不足・キメの乱れが「乾燥小ジワ」の主因とされる。
- 深掘り質問: 「シワが気になる部分は?」→ 目もと(部分的) / 顔全体(複数の年齢サイン)
- 該当製品: 部分的→ペプタイド ジェル(抗シワ効能評価試験済み) / 顔全体→フューチャー セラム(抗シワ効能評価試験済み)

### C. 毛穴・肌のざらつき
- 一般知識: 古い角質の滞留・ターンオーバーの乱れ・皮脂や乾燥の影響で毛穴が目立ちやすくなる。
- 深掘り質問: 「毛穴の悩みのタイプは?」→ ざらつき・角質のごわつき / 毛穴の目立ち・キメの乱れ
- 該当製品: リファイニング トーナー、ルミスパ iO

### D. くすみ・透明感
- 一般知識: ターンオーバーの乱れ・血行の滞り・乾燥が重なりくすみが生じるとされる。
- 該当製品: レディアント デイ SPF22、フューチャー セラム

### E. 乾燥・うるおい不足
- 一般知識: 角層の天然保湿因子(NMF)・皮脂膜の減少で水分保持力が低下し乾燥が進む。
- 該当製品: リッチ レイヤー クリーム、レディアント デイ SPF22

### F. 紫外線・乾燥ダメージ対策
- 一般知識: 紫外線は水分を奪い、コラーゲン・エラスチンの分解を促す一因とされる。
- 該当製品: レディアント デイ SPF22

### G. 洗顔・角質ケア
- 一般知識: 過剰な洗浄・摩擦や、逆に洗浄不足は肌トラブルの原因になり、肌質に合った洗浄方法が重要。
- 深掘り質問: 「現在の肌質は?」→ ノーマル・混合肌 / 乾燥肌 / 脂性肌 / 敏感肌
- 該当製品: ルミスパ iO + 該当肌質のトリートメント クレンザー(ノーマル/しっとり/さっぱり/デリケート)

### H. 頭皮・髪
- 一般知識: 髪のハリ・コシは頭皮環境に左右され、加齢・乾燥・血行不良で頭皮環境が乱れるとボリュームが出にくくなるとされる。
- 該当製品: ニュートリオール スカルプ&ヘアー セラム(ガルバニック スパ併用も案内可)

**注意**: 上記「一般知識」は皮膚科学の一般論として記載したもので、現時点で明確な出典(論文・教科書等)は付けていない。公開前に出典確認、または表現の再検討が必要。
